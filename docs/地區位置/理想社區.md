# 理想社區

由政府與[[伊捷科技]]攜手打造，座落於市中心繁華地段，以低廉租金與高規格管理吸引大批民眾。  
雖然存在著嚴格的居住限制與住戶間詭異的傳聞，但便宜又體面的生活環境仍讓申請入住者絡繹不絕。這裡，是現代都市中難得的「理想住所」——至少，表面如此。

# 關聯人物

- 勢力：[[伊捷科技]]
- 住戶：[[普魯托]]

# 事件紀錄

## 詭異鄰居

事件成員

- [[吳柏林]]
- [[林晨祥]]

近日，有理想社區的居民在網路討論區上發文，表示社區內出現一連串詭異現象，不僅多數住戶時常重複進行毫無意義的怪異動作，整體氛圍也讓人感到不安。該居民懷疑社區可能存在靈異問題，遂公開尋求外界協助。  
調查員們進入理想社區展開實地調查，並以住戶身分親自體驗當地生活。不料，調查員們在夜晚遭遇社區管理員的襲擊，事件急轉直下。最終，他們在部分清醒居民的協助下成功逃離社區，留下眾多未解之謎。
